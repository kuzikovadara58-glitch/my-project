# Электронный журнал тренировок — автоматизация

Desktop-приложение для автоматического заполнения электронного журнала
спортивных тренировок: вход в аккаунт, поиск нужного занятия, прикрепление
фотографии, отметка посещаемости и указание причин отсутствия.

Приложение рассчитано на тренера или администратора без навыков
программирования: утром он открывает приложение, видит тренировки на
сегодня и нажимает «Запустить автоматизацию». Для работы не требуются
Python, VS Code, терминал или редактирование файлов настроек.

> **Статус:** проект в разработке, этап 1 из 8 («Архитектура»). Готового
> приложения ещё нет — см. [CURRENT_STATE.md](CURRENT_STATE.md).

## Технологический стек (предварительный)

Python, PySide6, Playwright, SQLite, YAML (импорт/экспорт настроек), pytest,
Python `logging`, PyInstaller (сборка под Windows). Точные версии будут
зафиксированы на этапе «Данные» после проверки совместимости.

## Важные принципы проекта

- Журнал не заполняется до начала занятия и не заполняется автоматически
  задним числом за пропущенное по времени занятие.
- Никакие причины отсутствия не придумываются и не выбираются случайно.
- Используются только реальные фотографии с самой тренировки; метаданные
  фото не подделываются.
- Есть проверочный (dry-run) режим, который ничего не меняет в журнале.
- Секреты (логин/пароль от журнала) хранятся через системное хранилище
  учётных данных ОС, а не в коде или в репозитории.

Полный список постоянных правил — в [CLAUDE.md](CLAUDE.md).
